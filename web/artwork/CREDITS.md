# Real archive photographs

These are real online archive images used as illustrative placeholders in the guide. They are not stills from the scheduled synthetic demo, and no claim is made that the pictured material is part of a programme. Each image has a visible factual caption, credit, source link and placeholder note.

The downloaded JPEG bytes are unchanged. CSS supplies the monochrome presentation, crop and a separate coloured registration marker. No generated imitation archive image is bundled. The complete source URLs, reuse statements, retrieval dates and SHA-256 values are in `sources.json`.

- **Moon-walking simulation:** NASA / Langley. Source article: https://www.nasa.gov/centers-and-facilities/langley/50-years-ago-the-lunar-landing-research-facility/. NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/. Used as a factual informational reference with NASA credit; this does not suggest NASA endorsement.
- **Portable radio in a straw hat, 1931:** Nationaal Archief / Spaarnestad Photo / Het Leven, photographer unknown, SFA022812804. Retrieved from https://commons.wikimedia.org/wiki/File:Draagbare_radio_-_Radio_hat_(4193509510).jpg, which records the original Nationaal Archief Flickr Commons source and “No known copyright restrictions”. This is the archive’s stated status, rather than an invented CC0 grant.

Only the two JPEGs have public application routes. The source manifest and this note ship in the repository and container; they are not exposed as public file paths.
